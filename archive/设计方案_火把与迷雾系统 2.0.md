# 火把与迷雾系统 - 设计方案 v2.0

## 一、设计目标

将火把从“惩罚探索的倒计时”改为“辅助探索的主动工具”，让玩家不再被火把推着走，而是主动使用火把来获取信息优势。

核心改变：**走路不消耗火把，火把是探索的帮手，不是枷锁。**

---

## 二、火把系统

### 2.1 火把的定义

火把不再是一个随步数减少的数值，而是**本局剩余时间**。

- 初始火把时间：12-15分钟（720-900秒）
- 时间以秒为单位实时减少
- 玩家可在游戏中随时查看剩余时间

### 2.2 火把耗尽

- 火把时间归零视为本局失败（与之前一致）
- 时间耗尽时触发熄灭动画：屏幕逐渐变暗，火光熄灭特效，然后弹出结算界面

---

## 三、走路规则

**走路不消耗火把。**

玩家在地图中自由移动，步数不影响火把时间。这意味着：
- 玩家可以放心探索岔路和死胡同
- 回溯已探索区域没有惩罚
- 迷宫的规模不再是折磨，而是探索的乐趣

---

## 四、迷雾系统

### 4.1 基础视野

玩家周围始终存在一个有限的**基础视野范围**，范围外的区域被迷雾覆盖。

- 基础视野形状：以玩家为中心的**菱形区域**（曼哈顿距离）
- 基础视野半径：**曼哈顿距离2-3格**（即5×5或7×7菱形）
- 玩家走过的区域，在离开视野后**保留在地图上**（记忆地图），不被迷雾重新覆盖
- 迷雾只覆盖**从未到达过**的区域

### 4.2 迷雾显示规则

| 区域状态 | 基础视野内 | 基础视野外 |
|----------|-----------|-----------|
| 已探索区域 | 完全可见 | 地形可见（墙壁+通道），特殊元素按小地图记忆分层规则显示 |
| 未探索区域 | 完全可见 | 被迷雾完全覆盖 |

### 4.3 小地图整合

小地图的记忆分层规则保持不变（-1屏完整，-2屏无特殊元素，-3屏仅地形），但所有规则基于**已探索区域**生效。未探索区域统一显示为迷雾。

---

## 五、助燃剂系统（核心新增）

### 5.1 什么是助燃剂

助燃剂是玩家可以主动使用的**视野扩展工具**。使用后短暂大幅扩大视野范围，但会消耗火把剩余时间。

### 5.2 使用规则

| 参数 | 数值 |
|------|------|
| 触发方式 | 玩家主动点击助燃剂按钮 |
| 火把消耗 | 每次使用消耗30秒 |
| 视野扩大范围 | 曼哈顿距离5-6格（覆盖当前屏大部分区域） |
| 持续时间 | 20秒 |
| 冷却时间 | 无（可连续使用，但每次都会消耗时间） |
| 使用限制 | 火把剩余时间不足30秒时不可使用 |

### 5.3 助燃剂效果

**视野扩展**：持续时间内，玩家视野半径从基础2-3格扩大到5-6格，可以看清当前屏及相邻屏的部分地形。

**隐藏元素揭示**：助燃剂激活期间，基础视野无法看到的隐藏元素会短暂显示：
- 隐藏宝箱：平时不可见，助燃剂激活时短暂闪烁标记
- 隐藏区入口（特殊墙壁）：平时看起来像普通墙壁，助燃剂激活时墙壁上显示微弱标记
- （后续）怪物位置：平时在迷雾中不可见，助燃剂激活时显示轮廓

### 5.4 使用流程

1. 玩家在迷宫中点击“助燃剂”按钮
2. 确认使用（弹出确认提示或直接使用，待定）
3. 火把时间立即减少30秒
4. 视野范围扩大到5-6格，持续20秒
5. 屏幕边缘出现助燃剂激活的视觉提示（如淡金色光晕）
6. 20秒结束后视野恢复到基础范围，光晕消失

## 六、火把补给

### 6.1 补给方式

迷宫中分布**火把残骸**，玩家走过时自动拾取，恢复火把时间。

| 参数 | 数值 |
|------|------|
| 拾取方式 | 经过该格子时自动拾取 |
| 恢复时间 | 30秒或60秒（随机，60秒概率较低） |
| 分布密度 | 每屏1-2个，放置在岔路或通道旁 |
| 拾取反馈 | 音效 + 火把时间数字闪烁绿色 |

### 6.2 补给与助燃剂的循环

设计意图是让玩家产生“赚到了”的正向循环：

> 开助燃剂（-30秒）→ 看到附近有火把残骸 → 走过去拾取（+30秒）→ 净支出为0 → 同时发现了宝箱 → 玩家觉得自己很聪明

补给的存在让玩家**敢于使用助燃剂**，而不是囤积不用。

---

## 七、游戏节奏变化

### 7.1 新的核心循环

```
自由漫步（基础视野，不消耗火把）
    ↓
走到岔路口，不确定哪条路值得走
    ↓
主动开助燃剂（-30秒）→ 视野扩大20秒
    ↓
快速扫描周围地形，发现宝箱/火把残骸/出口方向
    ↓
规划路线，朝目标前进
    ↓
途中拾取火把残骸（+30秒）→ 净支出平衡
    ↓
到达宝箱、发现新区域、继续探索
    ↓
循环
```

### 7.2 玩家体验变化

| 之前（行走消耗火把） | 之后（助燃剂系统） |
|---------------------|-------------------|
| 每走一步都在失去东西 | 走路零成本，探索自由 |
| 被系统推着走，焦虑 | 主动使用工具，掌控感 |
| 岔路和死胡同是惩罚 | 岔路是机会，死胡同可能有隐藏 |
| 火把是枷锁 | 火把是资源，助燃剂是战术工具 |
| 探索=消耗 | 探索=发现 |

## 八、实现清单

### 8.1 需要修改的现有系统

| 系统 | 改动内容 |
|------|---------|
| 火把数值 | 从“步数消耗”改为“时间倒计时”，单位改为秒 |
| 移动系统 | 移除移动消耗火把的逻辑 |
| UI | 火把显示改为 MM:SS 格式的倒计时 |

### 8.2 需要新增的功能

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 基础视野迷雾 | 玩家周围曼哈顿距离2-3格的菱形视野，外部覆盖迷雾 | P0 |
| 助燃剂按钮 | 屏幕上的使用按钮，点击扣30秒，视野扩到5-6格，持续20秒 | P0 |
| 助燃剂视觉反馈 | 激活时屏幕边缘金色光晕，持续20秒后消失 | P1 |
| 火把残骸 | 地图上可拾取的补给点，经过自动拾取，恢复30或60秒 | P0 |
| 隐藏宝箱 | 仅在助燃剂激活时可见闪烁标记的宝箱类型 | P1 |
| 火把耗尽动画 | 时间归零时屏幕渐暗、火光熄灭特效 | P1 |

### 8.3 推荐参数

| 参数 | 建议值 |
|------|--------|
| 初始火把时间 | 720秒（12分钟） |
| 基础视野半径 | 曼哈顿距离2格（5×5菱形） |
| 助燃剂消耗 | 30秒/次 |
| 助燃剂视野半径 | 曼哈顿距离5格 |
| 助燃剂持续时间 | 20秒 |
| 火把残骸恢复量 | 30秒（常见）或60秒（稀有） |
| 火把残骸密度 | 每屏1-2个 |

## 九、后续扩展预留

以下功能本版本不实现，但设计已预留接口：

- **助燃剂等级**：某些持久型胶囊可增加助燃剂持续时间或扩大视野范围
- **怪物与迷雾**：怪物在迷雾中移动，助燃剂可短暂显示其轮廓
- **多人共享视野**：队友开启助燃剂时，其视野范围对全队短暂可见
- **特殊迷雾区域**：某些区域的迷雾更浓，基础视野更小，必须靠助燃剂通过
