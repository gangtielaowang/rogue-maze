## 新版 Boss 动作（大尺寸）

> 新版本的低帧率动作序列，用于 Boss 的实际游戏内行为。
> 图片尺寸统一为 **512 × 320 px**。
> 角色地面投影重心锚点：**x=256, y=256**（以图片左上角为原点）。
> 碰撞盒范围：以锚点为中心 **x±96, y±24**（即 192 × 48 的碰撞盒）。

### `monster-bigBoss_idle_*.png` — 面向右侧 Idle（23 帧）

- 文件编号：`00` ~ `22`
- 动作内容：Boss 面向画面右侧的待机循环动画

### `monster-bigBoss_walk_*.png` — 面向右侧行走（24 帧）

- 文件编号：`00` ~ `23`
- 动作内容：Boss 面向画面右侧的行走循环动画

### `monster-bigBoss_turnBack_*.png` — 转身（34 帧）

- 文件编号：`00` ~ `33`
- 动作内容：Boss 从面向画面右侧转身到面向画面左侧的完整转身动画（一次性动作，非循环）

## 尺寸记录

### 新版帧（idle / walk / turnBack）
